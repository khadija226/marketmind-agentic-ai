## 🔐 Locked Interface

MarketMind starts with a locked screen. The main workspace is not displayed until the user provides an OpenAI API key.

The key is kept in Streamlit session state for the current session and is not hard-coded into the repository.

**Never commit an API key to GitHub.**

## 🤖 Agents

- 📊 Market Analyst — trends, opportunities, competition, business implications
- 📰 News & Sentiment Analyst — supplied news/text, themes, sentiment, catalysts
- 🔎 Fundamental Researcher — company and financial information
- ⚠️ Risk Analyst — financial, market, operational, competitive, and regulatory risks
- 🧠 MarketMind Full Investigation — combines the analytical perspectives

## ⚙️ Local Setup

```bash
git clone YOUR-GITHUB-REPOSITORY-URL
cd marketmind-agentic-app
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

## 🚀 Streamlit Deployment

Use:

```text
Repository: YOUR-GITHUB-REPOSITORY
Branch: main
Main file path: app.py
```

Keep `app.py` and `requirements.txt` in the repository root.

## ⚠️ Disclaimer

MarketMind is an educational and research project. AI-generated analysis may be inaccurate or incomplete. The application does not claim real-time market information unless a real market-data source is connected. It is not personalized financial advice.
